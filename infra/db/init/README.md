SQL в этом каталоге — служебный bootstrap образа `supabase/postgres`, скопированный из официального self-hosted набора Supabase. Он создаёт пароли ролей платформы и схемы, без которых Auth, Realtime и Storage не стартуют.

Это не миграции приложения. Логику сервиса сюда не добавляют. Таблицы и политики RLS живут в `supabase/migrations/`, и там нет функций, триггеров и `pg_cron`.
