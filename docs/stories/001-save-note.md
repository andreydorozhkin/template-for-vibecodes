# User story

**Как** вошедший пользователь, **я хочу** сохранить короткую заметку, **чтобы** увидеть её в своём списке.

## Критерии приёмки

1. Дано пользователь не вошёл. Когда он открывает `/notes`. Тогда его отправляет на `/login`.
2. Дано пользователь вошёл. Когда он отправляет пустой текст. Тогда заметка не создаётся и форма показывает ошибку.
3. Дано пользователь вошёл. Когда он отправляет текст. Тогда приложение вызывает Edge Function `create-note`, а в списке появляется только его заметка.

## Не входит в задачу

- Редактирование и удаление заметок.
- Совместный доступ к чужим заметкам.

Эта история уже разобрана в `app/` и `supabase/functions/create-note`. Новые задачи — отдельные файлы в этой папке.
